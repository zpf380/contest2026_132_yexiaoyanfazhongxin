# 姿态守护 (Posture Guard)

基于 OpenVela 智能手表的端侧姿态识别快应用。使用手表内置 IMU 传感器采集运动数据，通过轻量级 CNN 模型在设备端完成实时姿态推理，无需云端支持。

## 核心功能

- **实时姿态识别**：站立、坐下、行走、抬手、摔倒 5 种姿态
- **端侧推理**：轻量级 1D-CNN 模型 (~2,800 参数)，纯 JS 实现
- **摔倒检测报警**：检测到摔倒时触发振动报警
- **低功耗设计**：自适应采样频率，后台自动暂停

## 技术架构

```
IMU 传感器 (25Hz)
    ↓ 原始加速度 [x, y, z]
传感器管理器 (环形缓冲区)
    ↓ 滑动窗口 (50 样本)
预处理器 (IIR滤波 → 重力去除 → Z-score → 特征提取)
    ↓ 15 维特征向量
推理引擎 (1D-CNN / 规则引擎)
    ↓ 姿态标签 + 置信度
投票平滑器 (最近 5 次结果)
    ↓ 稳定结果
UI 更新 + 历史记录 + 摔倒报警
```

## AIoT IDE 仿真调试

1. 在 AIoT IDE 中打开项目目录
2. 选择目标设备类型为 `watch`
3. 点击"运行"按钮启动仿真器
4. 应用启动后默认显示主监控面板
5. 点击"开始"按钮启动传感器采集和姿态识别

### 模拟传感器数据

仿真器环境下传感器 API 可能不可用，应用会自动降级到模拟模式：
- 内置模拟传感器数据生成器
- 模拟行走、站立、坐下、抬手、摔倒等场景
- 无需真实硬件即可测试完整功能流程

## 端侧部署

### 模型权重部署

1. 在 PC 端使用 Python 训练 1D-CNN 模型
2. 导出 INT8 量化权重 (~3KB)
3. 通过 `storage.set()` 将权重写入手表存储
4. 应用启动时自动加载缓存权重

### 训练数据格式

```json
{
  "features": [mean_x, var_x, max_x, min_x, zcr_x, ...],  // 15维
  "label": "walking"  // standing/sitting/walking/hand_raise/fall
}
```

## 边界处理

- **传感器异常**：NaN 检测 + 连续异常计数 + 自动停止
- **数据过滤**：异常幅值过滤 (< 0.1 或 > 30 m/s²)
- **低电量保护**：电量 < 20% 自动降低采样频率
- **后台管理**：应用进入后台 5 秒后自动暂停传感器
- **内存控制**：环形缓冲区限制最大 100 条数据

## 振动报警

检测到摔倒时触发振动：
- 模式：长震动 (`vibrator.vibrate({ mode: 'long' })`)
- 持续时间：3 秒后自动解除
- 防抖：同一摔倒事件不重复触发
